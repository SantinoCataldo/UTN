CONTEXTO HISTÓRICO

¿POR QUÉ
APARECE
BIG DATA?

Durante décadas usamos bases tradicionales (SQL) con un único servidor centralizado como motor de todo. Pero la llegada de la Web 2.0 (redes sociales, celulares y streaming) generó tanta información que el servidor único no la pudo almacenar.

1997

El Origen (NASA)

Michael Cox y David Ellsworth usan por primera vez el término "Big Data" para simulaciones aéreas.

2001

El Paradigma (3V)

El analista Doug Laney define las bases de las 3V (Volumen, Velocidad y Variedad), que en 2012 evolucionan a 5V.

2006

La Revolución (Hadoop)

Nace Apache Hadoop, democratizando el almacenamiento y procesamiento distribuido a gran escala.

PROBLEMÁTICA

LIMITACIONES DEL
MODELO RELACIONAL

01

Escalabilidad

Vertical vs. Horizontal. Scale-Up es costoso y limitado físicamente; repartir tablas SQL con JOINs destruye el rendimiento.

02

Estructura de Datos

Rígida vs. Flexible. Las tablas tradicionales exigen esquemas estrictos que chocan con la realidad desordenada de la Web 2.0.

03

Volumen y Velocidad

Límites de Rendimiento. Los motores clásicos colapsan ante el flujo incesante de datos a procesar en tiempo real.

04

Modelo Consistencia

ACID vs. BASE. La consistencia estricta de ACID bloquea y ralentiza escrituras masivas en comparación con la flexibilidad eventual de BASE.

DEFINICIÓN

¿QUÉ ES
BIG DATA?

Conjunto de tecnologías, métodos y arquitecturas diseñadas para capturar, almacenar, procesar y analizar volúmenes de datos tan grandes y complejos que no pueden manejarse con herramientas tradicionales.

No se trata solo de "muchos datos". Big Data implica una transformación paradigmática: procesamiento a gran escala, respuesta a alta velocidad, diversidad de formatos, cómputo distribuido y la capacidad de extraer valor e insights.

Procesamiento a Escala Alta Velocidad Diversidad Cómputo Distribuido Extracción de Valor
CARACTERÍSTICAS FUNDAMENTALES

LAS 5 V DEL BIG DATA

Volumen

Cantidad masiva: TB → PB → EB → ZB. Excede la capacidad de sistemas tradicionales.

1 ZB = 1 billón de GB
Velocidad

Generación y procesamiento en tiempo real. Crucial para detección de fraudes.

3,81 PB procesados / segundo
Variedad

Estructurados, semi-estructurados y no estructurados de múltiples fuentes.

80% datos no estructurados
Veracidad

Calidad, exactitud y fiabilidad. Limpieza, validación y gobernanza de datos.

27% datos con errores*
Valor

Transformar datos crudos en conocimiento accionable y ventaja competitiva.

$274B mercado 2026*

ECOSISTEMA TECNOLÓGICO · EXTRA

TECNOLOGÍAS CLAVE

Apache Hadoop

Framework open-source: almacenamiento distribuido (HDFS) + procesamiento paralelo (MapReduce). Bloques de 128 MB replicados en múltiples nodos.

HDFS MapReduce YARN

Apache Spark

In-memory, hasta 100x más rápido que MapReduce. Batch, streaming, ML y grafos.

Apache Kafka

Streaming distribuido para ingestión en tiempo real. Millones de eventos por segundo.

Apache Hive

Data warehouse sobre Hadoop. Consultas SQL (HiveQL) sobre datos en HDFS.

Cloud Big Data

AWS EMR, Google BigQuery, Azure HDInsight. Escalabilidad elástica bajo demanda.

Machine Learning

TensorFlow, PyTorch, Spark MLlib. Big Data como combustible para IA predictiva.

Bloques de 128 MB

Replicación x3

Data Locality
